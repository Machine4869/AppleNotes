# AppleNotes

在 Android 手机上查看通过 163 邮箱 IMAP 同步的 Apple 备忘录。

> **非 Apple 官方应用，与 Apple Inc. 无任何关联。**

---

## 为什么做这个

我有多台 Apple 设备，备忘录都散落在不同的设备上。

我只是想在 Android 手机上，用一个极简的 App 看这些备忘录，不需要账号体系、不需要后端、不需要广告和推送。

所以做了 AppleNotes：

- 直接连接 163 邮箱的 IMAP
- 笔记本质上还是 163 邮箱里的 HTML 邮件
- 没有服务器中转
- 没有富文本、标签、社交、云服务这些复杂功能

目前只适配了 **163 邮箱**。其他 IMAP 邮箱理论上可以连接，但没有做完整测试；有需要可以提 Issue。

---

## 功能

- 添加 / 编辑 / 切换 163 邮箱账户
- 从 163 的 `Notes` 邮箱同步备忘录
- 纯文本标题 + 正文编辑
- 搜索
- 排序
- 手动同步
- 返回时提示保存 / 不保存 / 取消
- 极简权限，无广告、无统计、无跟踪

## 不包含

- 富文本编辑
- 标签
- 笔记颜色
- UI 主题颜色选择
- 分享
- 导入
- 备份 / 恢复
- 错误报告
- 多目录
- iCloud / CloudKit 直连
- 任何后端服务

## 前置条件

使用前需要先准备好 163 邮箱和 Mac 上的备忘录同步。

### 1. 163 邮箱

- 登录 163 网页邮箱
- 打开 **设置 → POP3/SMTP/IMAP**
- 开启 **IMAP 服务**
- 生成 **授权码**

授权码不是邮箱登录密码。

### 2. Mac 上开启备忘录同步

- 打开 macOS **系统设置 → 互联网账户**
- 添加 **163 邮箱** 账户
- 在该账户下勾选 **备忘录**
- 在 Mac 备忘录里创建一条测试笔记
- 回到 163 网页邮箱，确认 `Notes` 目录里能看到这封邮件

### 3. Android

- Android 8.0 及以上
- 从 GitHub Releases 下载 APK 安装

---

## 使用

1. 安装 APK
2. 打开 AppleNotes
3. 点右上角设置
4. 添加账户
5. 填写：
   - 163 邮箱
   - 授权码
   - IMAP 服务器：`imap.163.com`
   - 端口：`993`
   - 安全：`SSL/TLS`
6. 保存后等待同步
7. 首页出现笔记后，点击即可编辑

## 数据与安全

### 没有后端

这个项目没有服务器、没有数据库后端、没有中转 API。

App 只做一件事：

```text
Android App  ←── IMAP over TLS ──→  163 邮箱
```

### 数据存在哪里

- 笔记正文：163 邮箱的 `Notes` 目录，本质是 HTML 邮件
- 本地缓存：手机 App 私有目录下的 SQLite 和 `.eml` 文件
- 账户信息：Android `AccountManager`
- App 没有申请存储卡全盘权限，也不读取其他 App 的文件

### 安全性

- IMAP 使用 SSL/TLS
- 授权码保存在 Android 账户系统里
- 没有云端备份
- 删除账户只清理本机数据库和缓存，不会删除 163 服务器上的邮件

### 需要注意

- 163 邮箱本身的安全由 163 负责

---

## 限制

- 目前只完整测试了 163 邮箱
- 只同步 163 的 `Notes` 邮箱，不支持多目录
- 纯文本编辑；原有富文本格式在编辑保存后会变成纯文本
- 不支持 iCloud 账户直接登录
